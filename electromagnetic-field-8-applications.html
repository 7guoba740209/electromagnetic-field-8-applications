复合场01

速度选择器

见到“正交电磁场 + 直线穿过” → 两力平衡，速度唯一。
v₀ = —

原理

让带电粒子穿过相互垂直的匀强电场和匀强磁场。粒子同时受恒定电场力 qE 与随速度变化的洛伦兹力 qvB，两力方向相反：只有速度恰好满足 qE=qvB（v=E/B）的粒子合力为零、沿直线穿过小孔 S；速度偏大偏小的粒子受力失衡而偏转、被挡板拦住。所以它只选速度，与粒子的质量、电荷量、电性都无关。

核心结论

1
平衡：qE = qvB → v = EB
2
若板间距 d、电压 U：v = UBd
3
v > U/Bd 向上偏；v < 则向下偏
教师点拨：选择条件与电荷量、质量、电性均无关——正负粒子的电场力和洛伦兹力同时反向，依然平衡。它只“选速度”，不选粒子。注意电场方向必须与洛伦兹力方向相反，否则无法平衡。
复合场02

磁流体发电机

见到“导电流体流经磁场” → 洛伦兹力分离正负电荷，两极生电。
电动势 —

原理

让高温电离的等离子体高速流过磁场。正负离子受洛伦兹力方向相反，分别被推向上下极板并堆积，两极间产生电势差。电荷越积越多、电场 E 越来越强，直到 qE=qvB 时不再堆积，电压稳定在 ε=Bdv。接上负载后电荷被导走，洛伦兹力继续分离电荷、持续对外供电——把流体的动能直接转化为电能。

核心结论

1
过程① 偏转沉积：qE < qvB → 电荷堆积、E 增大
2
过程② 平衡匀速：qE = qvB → E = vB
3
电动势 ε = Bdv（d 为两极间距）
4
接负载：U = εRR+r
教师点拨：本质是“运动导体切割磁感线”的微观版。判断极性别背结论：让正电荷随流体运动，用左手定则看它往哪极板跑，那块板就是正极。空载时电荷积累到电场力抵消洛伦兹力（qE=qvB），电压达到 ε；接负载后电荷被导走，洛伦兹力继续分离电荷，持续对外供电。
测量仪器03

电磁流量计

见到“测导电液体流量” → 磁场 + 两电极，电压正比于流速。
Q = —

原理

让导电液体流过磁场，液体中的正负离子受洛伦兹力上下分离，在管壁上下电极间建立电势差。它经历与发电机相同的自平衡过程：电荷堆积 → 电场增强 → qE=qvB 时电压稳定在 U=Bdv。电压表高内阻、只测压不取电流；因 Q ∝ U，表盘可直接刻度成流量，且无转动部件、不阻碍流动。

核心结论

1
过程① 偏转沉积：qE < qvB，电荷堆积、E 增大
2
过程② 平衡：qE = qvB → E = vB，离子匀速直线
3
电极电压 U = Ed = Bdv（d 为管径）
4
流量 Q = πd24v = πdU4B ∝ U
教师点拨：和磁流体发电机是同一套自平衡物理，区别只在“取不取负载电流”：发电机接负载、持续供电，这里电压表高内阻、只测压不取电流。注意 qvB 恒定不变，变的是 qE——从 0 增到相等就稳定了。流量公式里管径 d 约掉一次方，优点：无机械转动部件、不阻碍流体、可测腐蚀性液体。
测量仪器04

霍尔效应

见到“通电薄片处在高磁场中” → 横向电压，判断载流子正负。
UH = —

原理

让电流通过置于磁场中的导电薄片。定向移动的载流子受洛伦兹力偏向薄片一侧堆积，形成横向的霍尔电场 EH。当 qEH=qvB 时电压稳定，得 UH=IB/nqt。电压的正负取决于载流子的电性，所以测出极性就能判断是电子导电还是空穴导电。

核心结论

1
过程① 偏转沉积：qEH < qvB，载流子向一侧堆积、EH 增大
2
过程② 平衡：qEH = qvB → EH = vB，载流子匀速直线
3
由 I = nqvS 得 UH = IBnqt（t 沿磁场方向厚度）
4
电压正负 → 判断载流子是电子还是空穴
教师点拨：t 是沿磁场方向的厚度，不是薄片的宽或长，这是最容易错的地方。电子与空穴受洛伦兹力偏向同一侧，但堆积的电荷符号相反：电子导电时上表面带负电、电势低，空穴导电时上表面带正电、电势高——用电压表极性反推载流子类型，是高考常规考法。注意 qvB 恒定、变的是 qE，这一自平衡过程与磁流体发电机、电磁流量计同源。
粒子分析05

质谱仪

见到“加速后进入匀强磁场” → 半径由比荷决定，同位素分开。
落点间距 —

原理

先加速、后偏转：粒子经电压 U 加速得 v=√(2qU/m)，再进入匀强磁场走半圆，半径 r=mv/(qB) ∝ √(m/q)。比荷不同的离子半径不同，打在底片上的位置也不同（x=2r），于是按比荷大小分开排列成质谱——这就是分离同位素、测原子质量的依据。

核心结论

1
加速：qU = 12mv2 → v = √2qUm
2
偏转：r = mvqB = √2mUqB2
3
偏转距离（直径）x = 2r；比荷 qm = 8UB2x2
教师点拨：顺序不能乱：先加速、后偏转。粒子走半圆打回底片，偏转距离 x = 2r ∝ √m，所以质量大的落得远；比荷不相等的离子被分开，按比荷大小顺序排列，这就是分离同位素的依据。若前面加了速度选择器，则 r ∝ m/q，两种方案的依赖规律不同，别混用。
回旋06

回旋加速器

见到“D 形盒 + 交变电场” → 周期与速度无关，电压只管圈数。
Ek max —

原理

用磁场让带电粒子回旋、用电场反复加速来获得高能粒子。D 形盒内只有磁场、做匀速半圆，窄缝里只有交变电场、过缝即加速。巧妙之处在于回旋周期 T=2πm/(qB)与速度、半径都无关，固定频率的电场就能保证每次过缝都被正向加速。半径逐圈增大到盒边缘引出，最大动能只由 B 和盒半径决定。

核心结论

1
回旋周期 T = 2πmqB，与 v、r 无关
2
电场频率 f = qB2πm（必须与回旋频率相同）
3
最大动能 Ek max = q2B2R22m，与加速电压无关
教师点拨：先看运动：D 盒内只有磁场，粒子做匀速半圆（橙色弧，磁场不做功）；缝隙里只有电场，粒子沿水平方向做匀加速直线（绿色直线，电场做功）。两种运动严格分工，别把电场区也画成圆弧。半圆半径 r ∝ √k（第 k 次加速后），不是线性增大。最反直觉的一条：加大加速电压并不能提高最大动能，只能减少圈数、缩短加速时间；要提速只能加大磁场或 D 盒半径。周期与速度无关是经典力学的巧合，速度接近光速时失效——这正是回旋加速器的能量上限。
安培力07

磁电式电流表

见到“线圈在辐向磁场中转动” → 安培力矩正比于电流，刻度均匀。
偏角 θ = —

原理

把通电线圈放在蹄形磁铁与圆柱形铁芯之间的辐向磁场中。辐向磁场让线圈无论转到哪个角度，两条边始终垂直切割磁感线，安培力矩 M=NBIS 恒定；线圈转动时游丝产生反抗力矩 M′=kθ。平衡时 θ=(NBS/k)I，偏角与电流成正比，所以刻度均匀。

核心结论

1
辐向磁场中安培力矩 M = NBIS，与转角无关
2
游丝反抗力矩 M′ = kθ
3
平衡：θ = NBSkI → 刻度均匀
教师点拨：刻度均匀的关键不是“磁场匀强”，而是辐向磁场让线圈无论转到哪里，边都垂直切割磁感线，安培力矩恒定。若换成普通匀强磁场，力矩随角度按 cos 变化，刻度就不均匀了——这是教材插图容易被忽略的细节。
洛伦兹力08

圆周与螺旋

见到“速度斜射入磁场” → 分解垂直与平行，圆周叠加匀速直线。
r / T / h —

原理

粒子以速度 v 斜射入匀强磁场，分解为垂直分量 v⊥=vsinθ 与平行分量 v∥=vcosθ。垂直分量做匀速圆周（洛伦兹力提供向心力），平行分量不受力、保持匀速直线；两者叠加成螺旋线，每转一圈沿磁场方向前进一个螺距 h=v∥T。

核心结论

1
v⊥ = vsinθ → 圆周半径 r = mvsinθqB
2
周期 T = 2πmqB，与速率、角度无关
3
v∥ = vcosθ → 螺距 h = vcosθ·T
教师点拨：洛伦兹力永远垂直于速度，不做功——只改变方向不改变速率。平行磁场的分量不受力，所以螺旋是“圆周 + 匀速直线”的叠加。磁场对运动电荷不做功这个结论，是判断电磁场能量问题的第一依据。
